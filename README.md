# Mahmoud Hatem — Front-End Developer Portfolio

A cinematic, responsive portfolio website for **Mahmoud Hatem**, a Front-End Developer and AI student at HITU, Cairo.

## ✨ Features
- Cinematic video hero with portrait stage
- Dual light / dark theme (light is default, preference saved)
- Fully responsive — mobile, tablet, desktop
- Scroll-reveal animations
- Contact form with copy-to-clipboard for email/phone
- Project showcase with live demo & source links
- Leadership, Education, and Skills sections

## 🛠 Tech Stack
`HTML5` · `CSS3` · `Vanilla JS (ES6+)` · `Node.js` (dev server only) · `Vercel`

## 🚀 Run Locally
```bash
node server.js
```
Then open **http://localhost:3000**

## 🌐 Live Demo
Deployed on [Vercel](https://vercel.com) — connect this repo and it builds automatically.

## 📁 Project Structure
```
├── index.html          # Main page
├── style.css           # All styles (dark + light themes)
├── script.js           # Animations, scroll, copy, form
├── src/
│   ├── data.js         # All content (projects, skills, etc.)
│   └── navigation.js   # Header, mobile drawer, theme toggle
├── assets/             # Images & video
├── build.js            # Build script → dist/
├── vercel.json         # Vercel deployment config
└── server.js           # Local dev server
```
